`hub/` holds the shared build scripts, audits, downloads and run prompts. Each subject folder has its own README.

## Folder pattern (every subject)
`booklets/` finished PDFs · `reference/` syllabus + spec · `reports/` summaries · `build/` rebuild data.
Run scripts from the repo root, e.g. `python3 hub/scripts/physics/final_checks.py`.
